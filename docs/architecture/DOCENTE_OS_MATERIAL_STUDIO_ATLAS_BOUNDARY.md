# DOCENTE-OS-MATERIAL-01 — Atlas reuse and specialist material production boundary

**Status:** PROPOSED / HUMAN REVIEW REQUIRED / RUNTIME NOT AUTHORIZED  
**Date:** 2026-09-21  
**Decision reference:** proposed TRAMA-ADR-010

## Purpose

Define the teacher-facing material-preparation experience without turning Docente OS into a low-quality general graphics generator and without reducing Atlas to a file library.

## Teacher journey

From **Prima della lezione**, Docente OS knows the accepted class/discipline/year curriculum context, lesson purpose, sequence, previous work and material slots.

For each material need:

1. **Search Atlas first**.
2. Offer **Riutilizza | Adatta | Crea nuova**.
3. If new production is chosen, build a structured brief.
4. Send the brief to a specialist Material Studio capability.
5. Show one or more proposals to the teacher.
6. Allow modify/regenerate part/replace/exclude.
7. Attach the selected material to the lesson only after teacher decision.
8. After use, optionally offer **Rendi disponibile in Atlas** through the separate publication flow.

## Brief responsibility

Docente OS may include:
- discipline;
- grade;
- lesson title/purpose;
- teacher intent;
- curriculum references from the accepted Arena baseline;
- desired artifact role (LIM, student sheet, teacher guide, assessment, etc.);
- duration/use surface;
- relevant Atlas resource/pattern references;
- accessibility and output requirements.

The brief must not contain a duplicated authoritative curriculum copy when stable references suffice.

## Material Studio responsibility

Specialist production may cover:
- infographic/image generation;
- presentations;
- document layout;
- diagrams/maps;
- worksheets;
- assessments;
- future audio/video/interactives.

Provider selection is an implementation concern and is not authorized by this document.

## Teacher control

Generated proposals are never silently adopted. The teacher can:
- select;
- edit;
- regenerate;
- replace;
- exclude;
- keep local;
- publish later.

## Atlas boundary

Atlas remains the integral curriculum navigator and resource network. It provides reusable LO/resources/patterns and receives only explicitly published, eligible resources.

A local lesson material and an Atlas published resource remain distinct identities/states.

## Non-authorization

No runtime provider, automated publication, DOS-A1 activation, student-data transfer or shared persistence is authorized here.
