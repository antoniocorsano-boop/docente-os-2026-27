# Cattedra — conferma umana

Data: 2026-08-22  
Stato: IMPLEMENTATION NOTE

La conferma della Cattedra deve essere un'azione primaria, esplicita e immediata. Non deve richiedere di cambiare uno stato in un menu e poi ricordare un secondo pulsante di salvataggio.

Regole:

- associazione da verificare -> azione primaria **Conferma**;
- associazione confermata -> stato leggibile **Confermata**;
- modifica del monte ore -> azione separata, secondaria;
- eventuale ritorno a stato da verificare -> azione secondaria **Rimetti da controllare**;
- nessuna conferma crea slot nell'Orario;
- nessuna conferma modifica Piano annuale, Attività o Calendario.

Principio: **una decisione, un'azione**.
