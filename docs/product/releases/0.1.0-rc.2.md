Questa candidata sostituisce il codice applicativo di rc.1 esclusivamente per la remediation del flusso **Orario mobile + PDF raster + feedback teacher-first** emersa dalla validazione Android reale.

## Correzioni principali

- OCR locale limitato a raster max 1200 px con rimappatura delle coordinate;
- budget globale di 30 secondi per la fase locale, inclusa preparazione raster e bootstrap worker;
- lifecycle Tesseract reso retry-safe dopo timeout;
- progresso percepibile con linguaggio docente, percentuale solo durante il riconoscimento effettivo;
- preview automatica read-only finché il fallback manuale non è realmente necessario;
- progresso multipagina basato sulla posizione tra le pagine raster, non sul numero pagina PDF originale.
