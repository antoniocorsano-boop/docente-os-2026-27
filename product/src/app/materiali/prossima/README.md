# Materiali prossima lezione

La superficie espone il pacchetto didattico standard MDS-1 derivato esclusivamente dal `LessonMaterialRenderBundle` canonico: Proietta, Mappa visuale, Scheda studenti e Guida docente. La vista non introduce nuova persistenza o generazione autonoma e mantiene il comportamento fail-closed quando la preparazione non è risolta con sufficiente certezza.
